## 六、部署指南

### 环境准备

1. **数据库**
   ```bash
   mysql -u root -p < sql/interview_ai.sql
   mysql -u root -p < sql/interview_ai_audio_video_delta.sql
   mysql -u root -p < sql/interview_ai_vision_delta.sql
   ```

2. **Python AI服务**
   ```bash
   cd smartspeech_optimized
   pip install -r requirements.txt
   cp .env.example .env
   # 编辑.env，填写DEEPSEEK_API_KEY
   python -m backend.run  # 端口8765
   ```

3. **Spring Boot后端**
   ```bash
   cd interview-ai
   # 修改application-dev.yml配置
   mvn clean install
   cd interview-bootstrap
   mvn spring-boot:run  # 端口8080
   ```

4. **Vue前端**
   ```bash
   cd interview-ai/frontend
   npm install
   npm run dev  # 端口5173
   ```

## 八、已知问题与限制

### 当前限制
1. **Python服务依赖**：必须先启动Python AI服务，否则Java后端AI功能不可用
2. **浏览器兼容性**：仅支持Chrome/Edge等现代浏览器（需要WebRTC支持）
3. **HTTPS要求**：生产环境需HTTPS才能使用摄像头/麦克风
4. **API密钥**：需要自行申请DeepSeek API密钥

## 九、技术难点与解决方案

### 难点1：跨语言服务调用
**问题**：Java后端需要调用Python AI服务  
**解决**：通过AiApiClient封装HTTP调用，使用RestTemplate进行通信

### 难点2：实时视频帧处理
**问题**：前端采集的视频帧如何高效传输和分析  
**解决**：前端降采样（2-8帧/秒）+ Base64编码 + 后端异步处理

### 难点3：权限细粒度控制
**问题**：不同角色的权限差异化管理  
**解决**：Spring Security + RBAC + `@PreAuthorize`注解

### 难点4：评分可追溯性
**问题**：评分结果需要能够追溯到原始数据  
**解决**：保存完整的问答历史、视觉指标、评分公式和中间结果
