# 系统启动使用说明

## 📁 启动脚本说明

本项目提供了多种启动方式，选择最适合你的：

| 脚本文件 | 类型 | 说明 | 推荐度 |
|---------|------|------|--------|
| **启动系统.bat** | 批处理 | 双击即可启动，自动打开3个窗口 | ⭐⭐⭐⭐⭐ |
| **启动系统.ps1** | PowerShell | 功能完整，包含环境检查和端口检测 | ⭐⭐⭐⭐ |
| **停止系统.ps1** | PowerShell | 一键停止所有服务 | ⭐⭐⭐⭐ |

---

## 🚀 方式一：使用批处理脚本（最简单）

### 启动系统

**双击运行：** `启动系统.bat`

脚本会自动：
1. 打开 3 个 PowerShell 窗口
2. 依次启动 Python AI、Java 后端、Vue 前端
3. 等待服务初始化
4. 自动打开浏览器访问系统

### 停止系统

直接关闭 3 个 PowerShell 窗口，或者按 `Ctrl+C`

---

## 🔧 方式二：使用 PowerShell 脚本（推荐）

### 启动系统

**右键点击 → 使用 PowerShell 运行：** `启动系统.ps1`

或在 PowerShell 中执行：
```powershell
.\启动系统.ps1
```

**脚本功能：**
- ✅ 环境检查（Python、Java、Node.js、MySQL）
- ✅ 端口冲突检测和自动处理
- ✅ 服务启动验证
- ✅ 自动打开浏览器

### 停止系统

**运行：** `停止系统.ps1`

```powershell
.\停止系统.ps1
```

脚本会自动查找并停止所有服务进程。

## ❓ 常见启动问题

### Q1: 双击 .bat 文件闪退

**原因：** 环境检查失败

**解决：**
1. 右键点击 `启动系统.bat` → 编辑
2. 检查路径是否正确
3. 或者使用 PowerShell 脚本查看详细错误

---

### Q2: PowerShell 脚本无法运行

**错误：**
```
无法加载文件，因为在此系统上禁止运行脚本
```

**解决：**
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\启动系统.ps1
```

---

### Q3: 端口被占用

**PowerShell 脚本会自动检测并提示：**
```
⚠️ 端口 8080 (Java 后端) 已被占用 (PID: 12345)
是否关闭占用端口的进程并继续？(y/n)
```

输入 `y` 自动关闭占用进程。

**手动处理：**
```powershell
# 查找占用进程
Get-NetTCPConnection -LocalPort 8080 | Select-Object OwningProcess

# 停止进程
Stop-Process -Id <进程ID> -Force
```

---

### Q4: Python 服务启动失败

**错误：** `虚拟环境不存在`

**解决：**
```powershell
cd smartspeech_optimized
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### Q5: Java 后端启动失败

**错误：** `Unable to find a suitable main class`

**原因：** 在错误的目录执行

**解决：**
确保在 `interview-bootstrap` 目录执行，或使用启动脚本。

---

### Q6: MySQL 连接失败

**错误：** `Communications link failure`

**检查：**
1. MySQL 服务是否启动
   ```powershell
   Get-Service MySQL*
   ```

2. 数据库是否已创建
   ```powershell
   mysql -u root -p -e "SHOW DATABASES LIKE 'interview_ai';"
   ```

3. 密码是否正确（`application-dev.yml` 中的 `password`）

## 🎯 启动顺序说明

**必须按以下顺序启动：**

```
1. Python AI (8765)
    ↓
2. Java 后端 (8080) ← 依赖 Python AI
    ↓
3. Vue 前端 (5173)  ← 调用 Java 后端
```

**为什么要按顺序？**
- Java 后端启动时会检测 Python AI 服务
- 如果 Python AI 未启动，Java 后端会报警告（但不影响启动）
- 前端需要 Java 后端提供 API

## 🔧 自定义配置

### 修改端口

如果端口冲突，可以修改配置：

**Python AI 端口（8765）：**
- 文件：`smartspeech_optimized/.env`
- 配置：`APP_PORT=8765`

**Java 后端端口（8080）：**
- 文件：`interview-ai/interview-bootstrap/src/main/resources/application-dev.yml`
- 配置：`server.port: 8080`

**Vue 前端端口（5173）：**
- 文件：`interview-ai/frontend/vite.config.js`
- 配置：`server.port: 5173`

⚠️ **注意：** 修改端口后需要同步更新所有引用该端口的配置！

## 🛑 停止系统

### 方式 1：使用脚本

```powershell
.\停止系统.ps1
```

### 方式 2：手动关闭

关闭 3 个 PowerShell 窗口

### 方式 3：强制停止

```powershell
# 停止所有 Java 进程
Stop-Process -Name java -Force

# 停止所有 Python 进程
Stop-Process -Name python -Force

# 停止所有 Node 进程
Stop-Process -Name node -Force
```

⚠️ **注意：** 强制停止可能导致数据丢失，请谨慎使用！
