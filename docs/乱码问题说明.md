# 批处理文件乱码问题说明

## ❓ 为什么会出现乱码？

### 问题原因

你遇到的错误：
```
'閰嶇疆' 不是内部或外部命令...
'渚濊禆瀹夎瀹屾垚' 不是内部或外部命令...
```

这是**文件编码问题**：

1. **批处理文件 (.bat)** 默认使用 **GBK/ANSI** 编码（Windows 中文版）
2. 我创建的文件使用了 **UTF-8** 编码
3. 当 Windows 用 GBK 编码读取 UTF-8 文件时，中文就会变成乱码

### 编码对比

| 文字 | UTF-8 编码 | GBK 解析 | 结果 |
|------|-----------|---------|------|
| 配置 | E9 85 8D E7 BD AE | 閰嶇疆 | ❌ 乱码 |
| 依赖 | E4 BE 9D E8 B5 96 | 渚濊禆 | ❌ 乱码 |

---

## ✅ 解决方案

### 方案 1：使用 PowerShell 脚本（推荐）

PowerShell 原生支持 UTF-8，不会出现乱码。

**文件列表：**
- ✅ **安装所有依赖.ps1** - PowerShell 版本
- ✅ **1-启动Python服务.ps1** - PowerShell 版本
- ✅ **安装所有依赖-启动器.bat** - 自动调用 PowerShell

**使用方法：**

```powershell
# 方法 1：直接运行 PowerShell 脚本
.\安装所有依赖.ps1

# 方法 2：使用启动器（双击即可）
安装所有依赖-启动器.bat

# 如果提示无法运行脚本，执行：
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
.\安装所有依赖.ps1
```

### 方案 3：转换编码（不推荐）

将 `.bat` 文件转为 ANSI/GBK 编码：

1. 用记事本打开 `.bat` 文件
2. 文件 → 另存为
3. 编码选择：**ANSI**
4. 保存

**缺点：**
- 每个文件都要手动转换
- 在其他编码系统（如 UTF-8 系统）会出问题

## ❓ 常见问题

### Q1: PowerShell 提示无法运行脚本？

**错误信息：**
```
无法加载文件 xxx.ps1，因为在此系统上禁止运行脚本。
```

**解决方案：**
```powershell
# 临时允许（推荐）
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process

# 或永久允许（需要管理员权限）
Set-ExecutionPolicy RemoteSigned
```

---

### Q2: 为什么 .bat 文件还要保留？

**原因：**
- 双击 `.bat` 更方便（无需右键 → PowerShell）
- `.bat` 可以调用 `.ps1`（启动器模式）
- 兼容不熟悉 PowerShell 的用户

**推荐方案：**
- 核心逻辑用 `.ps1` 编写
- 用 `.bat` 启动器调用 `.ps1`

---

### Q3: 已经有乱码的 .bat 文件怎么办？

**不用管它！** 直接使用新的 `.ps1` 文件即可。

或者删除乱码的 `.bat` 文件：
```powershell
Remove-Item "安装所有依赖.bat"
```
