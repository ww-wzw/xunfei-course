## 📝 使用流程

### 新用户（首次使用）

```
1. 阅读 README.md（了解项目）
   ↓
2. 阅读 环境配置指南.md（配置环境）
   ↓
3. 运行 安装所有依赖.ps1（安装依赖）
   ↓
4. 配置 MySQL 数据库（按指南操作）
   ↓
5. 运行 0-环境检查.bat（验证配置）
   ↓
6. 双击 启动系统.bat（启动系统）
   ↓
7. 访问 http://localhost:5173（使用系统）
```

### 老用户（日常使用）

```
1. 双击 启动系统.bat
   ↓
2. 访问 http://localhost:5173
   ↓
3. 使用完毕后运行 停止系统.ps1（或直接关闭窗口）
```
