# 面试AI系统 - 启动脚本使用说明

## 快速启动

### 方式1：双击运行（推荐）
1. 双击 `start-all.ps1` 文件
2. 如果出现安全提示，右键点击 → 选择"使用PowerShell运行"

### 方式2：命令行运行
```powershell
# 启动所有服务
.\start-all.ps1

# 停止所有服务
.\stop-all.ps1
```

## 服务说明

启动后会自动打开3个窗口：
1. **Python AI服务窗口** - 运行在 http://127.0.0.1:8765
2. **Spring Boot后端窗口** - Spring Boot应用
3. **浏览器窗口** - 前端界面 http://localhost:5173

## 注意事项

### 首次运行前准备
1. **数据库初始化**（仅首次需要）
   - 确保MySQL已安装并运行
   - 执行SQL初始化脚本创建数据库和表

2. **Python环境**
   - 确保已安装Python及所需依赖
   - 在 `smartspeech_optimized` 目录运行：
     ```bash
     pip install -r requirements.txt
     ```

3. **Java环境**
   - 确保安装了正确版本的Java（检查项目要求）
   - 确保Maven已配置

### 如果脚本执行被阻止

Windows可能阻止运行PowerShell脚本，解决方法：

```powershell
# 以管理员身份打开PowerShell，运行：
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

# 然后输入 Y 确认
```

### 停止服务

**方法1：使用停止脚本（推荐）**
```powershell
.\stop-all.ps1
```

**方法2：手动关闭**
- 关闭各个PowerShell窗口即可停止对应服务

**方法3：任务管理器**
- 打开任务管理器
- 结束 python.exe 和 java.exe 进程

## 故障排除

### Python AI服务无法启动
- 检查端口8765是否被占用
- 检查Python依赖是否安装完整
- 查看Python服务窗口的错误信息

### Spring Boot后端无法启动
- 检查Java版本是否符合要求
- 检查Maven配置是否正确
- 检查数据库连接配置

### 前端页面无法访问
- 确保前端开发服务器已运行（通常是 `npm run dev`）
- 检查端口5173是否被占用

### 端口冲突
如果端口被占用，可以：
```powershell
# 查看占用端口的进程
netstat -ano | findstr :8765
netstat -ano | findstr :5173

# 根据PID结束进程
taskkill /PID <进程ID> /F
```

## 服务访问地址

- **前端界面**: http://localhost:5173
- **Python AI服务**: http://127.0.0.1:8765
- **Spring Boot后端**: 根据配置的端口（通常是8080）

## 开发模式

如果需要单独启动某个服务：

```powershell
# 仅启动Python AI服务
cd smartspeech_optimized
python -m backend.run

# 仅启动Spring Boot后端
cd interview-ai
mvn spring-boot:run

# 仅启动前端（如果使用Vite）
npm run dev
```
