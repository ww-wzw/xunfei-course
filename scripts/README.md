# Scripts 目录说明

本目录包含所有启动和配置脚本。

---

## 🚀 启动脚本

| 脚本 | 说明 | 使用方式 |
|------|------|----------|
| **启动系统.ps1** | 完整的启动脚本（推荐） | `.\启动系统.ps1` |
| **停止系统.ps1** | 停止所有服务 | `.\停止系统.ps1` |

---

## 📦 配置脚本

| 脚本 | 说明 | 使用方式 |
|------|------|----------|
| **安装所有依赖.ps1** | 一键安装所有依赖 | `.\安装所有依赖.ps1` |
| **重建Python环境.ps1** | 重建 Python 虚拟环境 | `.\重建Python环境.ps1` |

---

## 🔧 其他工具脚本

| 脚本 | 说明 |
|------|------|
| **1-启动Python服务.ps1** | 单独启动 Python AI 服务 |
| **start-all.ps1** | 备用启动脚本 |
| **stop-all.ps1** | 备用停止脚本 |

---

## 💡 使用建议

### 首次使用

```powershell
# 1. 安装依赖
.\安装所有依赖.ps1

# 2. 启动系统
.\启动系统.ps1
```

### 日常使用

**推荐：** 直接双击根目录的 `启动系统.bat`

或在本目录执行：
```powershell
.\启动系统.ps1
```

### 停止系统

```powershell
.\停止系统.ps1
```

---

## ⚠️ 注意事项

1. 所有 PowerShell 脚本需要执行权限：
   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   ```

2. 如果遇到问题，查看 `../docs/` 目录中的文档

3. 环境配置问题参考 `../docs/环境配置指南.md`
