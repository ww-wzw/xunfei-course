## 🔍 故障排查

### 问题 1：Python 依赖安装失败

**解决方案：**
```bash
# 升级 pip
python -m pip install --upgrade pip

# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问题 2：Java 编译报错

**解决方案：**
```bash
# 清理缓存重新编译
.\mvnw.cmd clean install -DskipTests -U
```

### 问题 3：前端启动报错 `ECONNREFUSED`

**原因：** 后端未启动或端口不对

**解决方案：**
1. 确认 Java 后端已启动（8080 端口）
2. 检查 `frontend/vite.config.js` 代理配置

### 问题 4：无法连接 Python AI 服务

**检查：**
```bash
# 测试 Python 服务是否可访问
curl http://127.0.0.1:8765/api/ai/health
```

应该返回：
```json
{"ok": true, "name": "智能体模拟面试系统", "capabilities": {...}}
```

## 📌 重要提示

1. **启动顺序不能乱：** Python(8765) → Java(8080) → Vue(5173)
2. **端口冲突：** 如果端口被占用，需要修改配置或关闭占用进程
3. **API Key：** DeepSeek API Key 有配额限制，如果用完需要更换
4. **Redis（可选）：** 当前配置中 Redis 被注释掉了，暂时不需要
5. **MinIO（可选）：** 文件存储功能需要，但可以先不配置
