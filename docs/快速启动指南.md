## ⚠️ 常见问题

### Q1: Java 后端启动失败 - JAVA_HOME 错误
**解决：**
```powershell
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot"
```

### Q2: Python 虚拟环境激活失败
**解决：**
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.venv\Scripts\Activate.ps1
```

### Q3: 端口被占用
**查找占用进程：**
```powershell
Get-NetTCPConnection -LocalPort 8080 | Select-Object OwningProcess
Stop-Process -Id <进程ID>
```

### Q4: MySQL 连接失败
**检查 MySQL 服务：**
```powershell
Get-Service MySQL*
Start-Service MySQL80  # 或对应的服务名
```

## 📌 课设提交时的注意事项

1. **环境配置说明**
   - 需要 Python 3.10 虚拟环境
   - 需要 Java 17（注意 JAVA_HOME 配置）
   - 需要 Node.js 20+
   - 需要 MySQL 8.0

2. **启动顺序**
   - 必须先启动 Python AI 服务
   - 再启动 Java 后端
   - 最后启动前端

3. **配置文件**
   - `smartspeech_optimized/.env` - DeepSeek API Key
   - `interview-ai/.../application-dev.yml` - 数据库密码

4. **测试数据**
   - 数据库已包含测试用户和场景
   - 可以直接登录测试
